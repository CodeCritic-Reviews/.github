# CodeCritic Reviews

**AI code review for GitHub pull requests** — GitHub Action, VS Code / Cursor extension, and REST API. Free tier, 25+ languages.

- **[CodeCritic Review — GitHub Action](https://github.com/CodeCritic-Reviews/review-action)** — AI review on every pull request, findings posted as PR comments. [Install from GitHub Marketplace](https://github.com/marketplace/actions/codecritic-review).
- **[Website](https://code-critic.com)** — paste code in the browser, review GitHub PRs, or call the API. [Free code review, no card needed](https://code-critic.com/free-code-review).
- **[VS Code & Cursor extension](https://marketplace.visualstudio.com/items?itemName=CodeCriticReviews.codecritic)** — AI code review in the editor, same API key as the web app.
- **[Blog](https://blog.code-critic.com)** — code review practices, security notes, and product updates.

## What the review looks like

Open a pull request and CodeCritic posts a comment with line-level findings: bugs, security risks, and quality issues with plain-language fixes. You keep merge ownership — findings are advisory, and every suggestion is meant to be verified by a human.

## Honest scope

CodeCritic uses AI models to analyze code. Results may contain inaccuracies and are not a substitute for human review of critical systems. We document [what AI review does not catch](https://code-critic.com/ai-code-review-limitations).
